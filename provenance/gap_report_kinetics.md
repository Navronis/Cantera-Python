# Kinetics gap report

The current Python kinetics implementation covers scalar Arrhenius-family rate evaluation, elementary mass-action progress/source terms, third-body default-compensated effective concentrations, and explicit irreversible reaction-order validation. Third-body mass-action multipliers are applied to both forward and reverse scalar progress rates as in `BulkKinetics::updateROP`.

Lindemann, Troe, SRI, and Tsang rates can now consume effective non-mass-action collider concentrations through `FalloffReaction`; they do not receive a second mass-action multiplier. The Tsang branch uses the pinned `Fcent = A + B*T` broadening formula at both dilute and dense collider limits. `ElementaryReaction` also derives ideal-gas reverse coefficients as `kf / Kc`, where `Kc` follows `BulkKinetics::getEquilibriumConstants` using current-pressure standard chemical potentials and standard concentration. Remaining items include full reaction parsing and collider-name handling, duplicate reaction handling, thermochemical reverse rates for nonideal/multiphase systems, surface/interface kinetics, electrochemical corrections, coverage dependencies, mechanism registries, rate derivatives for every family, and the native kinetics state/cache behavior. These remain `PARTIAL` or `NOT_AUDITED` in `master_port_matrix.jsonl`; no completion claim is made.

Validation currently consists of equation-level tests and randomized scalar comparisons against released Cantera 3.2.0. An exact pinned-commit native oracle and full upstream kinetics test migration are still required.
